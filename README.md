# Carry desk

Браузерная стратегия: валютные пары, фонды LQDT и TMON, короткие рублёвые облигации.

Токен Т-Инвестиций вводится на странице и в репозиторий не сохраняется. Запросы к брокеру идут с сервера по IPv4. Если VPN подменяет сертификат, запрос повторяется. Заявки скрипт не отправляет.

```bash
node server.mjs
```

Откройте страницу сервера. Порт по умолчанию 8080, другой задаётся переменной `PORT`.
