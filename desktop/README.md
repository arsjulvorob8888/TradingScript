# Currency Bond + Short Perpetual Futures Strategy
## Professional Desktop Trading Application for T-Bank

### Описание
Десктопное приложение для управления динамической стратегией:
- Long надёжные валютные облигации (AAA, высокая ликвидность)
- Short вечные валютные фьючерсы (USDRUBF, CNYRUBF)
- Динамическая аллокация на основе mean-reversion фандинга
- Тактические покупки на просадках цен облигаций
- Полная аналитика, дашборды и графики

### Установка
```bash
cd trading_app
pip install -r requirements.txt
```

### Запуск
1. Получите токен API в личном кабинете Т-Банк (Инвестиции → Настройки → Токены)
2. Вставьте токен в поле в приложении (или задайте в .env как TBANK_TOKEN)
3. Запустите:
```bash
python main.py
```

### Структура
- `main.py` — главное окно приложения (PyQt6)
- `config.py` — токен, список надёжных инструментов, параметры
- `api_client.py` — обёртка над T-Bank Invest API
- `strategy.py` — логика динамической стратегии
- `requirements.txt` — зависимости

### Важные замечания
- По умолчанию используется **песочница** (sandbox). Для реальной торговли измените `USE_SANDBOX = False` в `config.py`
- В текущей версии только проверенные высоколиквидные инструменты. Мусорные бумаги будут добавлены позже
- Фандинг в демо-режиме показан на исторических данных. Для live-данных потребуется дополнительная интеграция с MOEX ISS или расчёт через операции
- Приложение предназначено для управления и аналитики. Автоматическое исполнение ордеров требует дополнительной настройки и тестирования
